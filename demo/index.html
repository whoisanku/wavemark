Avatars made of waves.

Any string → 3–5 wave sources → interference pattern. Same name, same avatar, forever.

Style
Motion

Animation is off because your OS asks for reduced motion.

Twelve strangers

Handles, emails, ids — each hashed into its own wave field. 60 px.

    In a thread

    Tiny sizes are where identicons earn their keep. 24 px.

      Usage

      One import. No build step required.

      npm install wavemark

import { wavemark } from 'wavemark';

wavemark('ankit', canvas, { style: 'nodal' });          // draw into a canvas
wavemark('ankit', canvas, { breathe: true });           // slow in-place motion
img.src = wavemark.toDataURL('ankit', 64);              // PNG data URL

// straight from a CDN, no bundler:
import { wavemark } from 'https://cdn.jsdelivr.net/npm/wavemark/+esm';
